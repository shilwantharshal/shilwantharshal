## My approach

I build tools that remove real costs and real friction, not demo apps.

- Start with the problem, then pick the tech.
- Ship a working version first, polish it after.
- Keep it simple enough that someone else can run it in five minutes.
- Security and reliability are features, not extras.

## What I'm building

### `⚡ BoltPe`

> Payments without the middleman.

A self-hosted UPI payment gateway for India with **0% fees**. Money goes straight into the merchant's own bank account, with no aggregator approval and no 2% cut. It detects payments automatically from bank SMS and Gmail alerts, sends HMAC-signed webhooks, and plugs into any site with a single script tag.
